# Public demo

The project page is https://sourya-dce.netlify.app/ and the recorded run viewer is https://sourya-dce.netlify.app/demo.html. Both are public and need no login.

The source is in `website/`. There is no frontend build step. `demo-data/` contains the original JSON responses from C++ runs; the viewer reads those files and shows task state, worker sessions, attempts, and results. The values are not generated by a browser simulation.

The C++ coordinator and workers still run locally or in Docker. Netlify serves the public overview and recorded demo, not the TCP cluster.

To publish changes, sign in to Netlify and run `sh scripts/deploy-demo.sh`. That script deploys `website/` to the existing site. `netlify.toml` defines the publish directory and response headers. Netlify credentials and local project state are not tracked in Git.

The older GitHub Pages address is retained as a redirect to Netlify so existing links keep working.
